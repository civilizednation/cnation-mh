사용법

1. 읽는 순서

  1. 서재에서 작품 표지를 누릅니다.
  2. 권 목록에서 읽을 권을 누릅니다. (읽던 권은 ● 표시와 진행 막대, 다 읽은 권은 '완독' 표시)
  3. 만화 보기 화면이 열립니다. 마지막으로 보던 곳이 있으면 거기서부터 이어서 열립니다.

서재 맨 위의 이어 보기 카드를 누르면 가장 최근에 읽던 페이지로 바로 들어갑니다.

2. 페이지 넘기기

다음 페이지왼쪽 탭
메뉴 표시/숨김가운데 탭
이전 페이지오른쪽 탭

기본 설정(오른쪽 → 왼쪽, 만화 방향) 기준

  • 화면 왼쪽 탭 → 다음 페이지, 화면 오른쪽 탭 → 이전 페이지 (종이 만화책처럼 왼쪽으로 넘어갑니다)
  • 스와이프: 손가락을 오른쪽으로 밀면 다음 페이지, 왼쪽으로 밀면 이전 페이지
  • 화면 가운데 탭 → 위·아래 메뉴를 숨기거나 다시 보이게 합니다. 페이지를 넘기면 메뉴는 자동으로 숨겨집니다.
  • 설정에서 읽기 방향을 왼쪽 → 오른쪽으로 바꾸면 좌우가 반대로 동작합니다.
  • 세로 스크롤 보기에서는 위아래로 스크롤해서 읽고, 탭하면 메뉴만 표시/숨김됩니다.
  • 확대: 두 손가락으로 벌리면 확대됩니다. 확대한 상태에서는 페이지가 넘어가지 않으니, 원래 크기로 줄인 뒤 넘기세요.

3. 위쪽 아이콘 (만화 보기 화면)

  • 뒤로권 목록으로 돌아갑니다. 옆에 작품 제목과 권 번호가 표시됩니다.
  • 책갈피지금 보는 페이지를 책갈피에 저장합니다. 저장되면 아이콘이 채워지고, 다시 누르면 해제됩니다.
  • 책갈피 목록이 작품에 저장한 책갈피를 모아 보고, 누르면 그 페이지로 바로 이동합니다. ✕ 로 삭제.
  • 페이지 목록이 권의 모든 페이지를 작은 그림으로 보여 줍니다. 원하는 페이지를 누르면 바로 이동합니다.
  • 보기 설정보기 방식·읽기 방향·화면 맞춤·화질을 바로 바꾸고, 저장 공간을 정리합니다.
  • 전체 화면태블릿·PC처럼 화면이 넓을 때만 보입니다. 휴대폰은 홈 화면에 추가해서 실행하면 전체 화면으로 열립니다.

4. 아래쪽 막대 (만화 보기 화면)

  • 이전 권 / 다음 권 버튼으로 바로 옆 권으로 이동합니다.
  • 가운데 슬라이더를 끌어서 원하는 페이지로 빠르게 이동합니다. 만화 방향일 때는 슬라이더도 오른쪽이 첫 페이지입니다.
  • 아래 숫자는 현재 페이지 / 전체 페이지입니다. 반쪽 보기에서는 지금 보는 쪽(오른쪽·왼쪽)도 함께 표시됩니다. (예: 8 / 118 · 왼쪽)
  • 권의 마지막 페이지에서 한 번 더 넘기면 '다 읽었습니다' 창이 뜨고, 다음 권으로 바로 넘어갈 수 있습니다.

5. 보기 방식

  • 한 페이지: 이미지 한 장씩 화면에 맞춰 봅니다.
  • 두 페이지: 두 장을 나란히 펼쳐 봅니다. 가로로 든 태블릿·PC에 알맞습니다.
  • 반쪽 보기: 두 쪽이 한 장으로 스캔된 이미지를 반으로 잘라 한 쪽씩 보여 줍니다. 세로로 든 휴대폰에 알맞습니다. (기본값)
  • 세로 스크롤: 모든 페이지를 위아래로 이어서 봅니다.

서재 오른쪽 위 톱니바퀴(설정)에서 만화를 열기 전에 미리 정해 둘 수 있고, 보는 중에는 위쪽 보기 설정 아이콘으로 바꿀 수 있습니다.

6. 서재·권 목록 화면

  • 책갈피 목록권 목록 화면 오른쪽 위. 이 작품의 책갈피를 모아 봅니다.
  • 새로고침권 목록 화면 오른쪽 위. Google Drive에 새 권을 올렸을 때 목록을 바로 다시 불러옵니다. (목록은 12시간마다 자동 갱신)
  • 설정서재 오른쪽 위. 제작자 정보와 보기 설정, 저장 공간 관리.

8. 알아 두면 좋은 점

  • 홈 화면에 추가하면 앱처럼 전체 화면으로 열립니다. 아이폰은 Safari 공유 버튼 → '홈 화면에 추가', 안드로이드는 Chrome 메뉴(⋮) → '홈 화면에 추가'.
  • 이어 보기 위치와 책갈피는 기기(브라우저)마다 따로 저장됩니다. 다른 휴대폰·PC에서는 처음부터 보입니다.
  • 한 번 본 페이지는 기기에 저장되어 다시 열 때 빨리 뜹니다. 공간이 부족하면 설정 → 저장 공간에서 지울 수 있습니다.

Google Drive 연결 설정

만화는 Google Drive 에서 서비스 계정으로 불러옵니다. 비밀 키는 Vercel 서버에만 저장되고 브라우저에는 보이지 않습니다.

  1. Google Cloud 콘솔에서 Google Drive API 를 사용 설정합니다.
  2. IAM 및 관리자 → 서비스 계정 → 만들기 (역할은 주지 않아도 됨)
  3. 만든 서비스 계정 → 키 → 키 추가 → JSON 으로 키 파일을 받습니다.
  4. Vercel → Settings → Environment Variables 에 GOOGLE_SERVICE_ACCOUNT 로 키 파일 내용 전체를 넣고 재배포합니다.
  5. Google Drive 에서 작품 폴더를 서비스 계정 이메일에 뷰어로 공유합니다.
