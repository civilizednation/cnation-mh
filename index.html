Google Drive 연결 설정

만화는 Google Drive 에서 서비스 계정으로 불러옵니다. 비밀 키는 Vercel 서버에만 저장되고 브라우저에는 보이지 않습니다.

  1. Google Cloud 콘솔에서 Google Drive API 를 사용 설정합니다.
  2. IAM 및 관리자 → 서비스 계정 → 만들기 (역할은 주지 않아도 됨)
  3. 만든 서비스 계정 → 키 → 키 추가 → JSON 으로 키 파일을 받습니다.
  4. Vercel → Settings → Environment Variables 에 GOOGLE_SERVICE_ACCOUNT 로 키 파일 내용 전체를 넣고 재배포합니다.
  5. Google Drive 에서 작품 폴더를 서비스 계정 이메일에 뷰어로 공유합니다.
